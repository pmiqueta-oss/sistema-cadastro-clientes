# Sistema de Cadastro de Clientes (SQL)

Projeto prático desenvolvido para estudos e aplicação de comandos SQL utilizando **SQLite** e o gerenciador **DBeaver**. O objetivo é demonstrar a estruturação de um banco de dados relacional e a realização das principais operações de manipulação de dados (CRUD).

## 🛠️ Tecnologias Utilizadas
* **SQL** (Linguagem de Consulta Estruturada)
* **SQLite** (Banco de dados leve e embarcado)
* **DBeaver** (Ferramenta de gerenciamento de banco de dados)

## 📁 Estrutura do Projeto
Os scripts estão organizados de forma sequencial para facilitar o entendimento do fluxo de banco de dados:

1. `01_criar_tabela.sql` - Criação da estrutura da tabela de clientes (DDL).
2. `02_inserir_clientes.sql` - Inserção de registros iniciais de clientes (DML).
3. `03_consultar_clientes.sql` - Consultas com filtros e recuperações de dados (DQL).
4. `04_atualizar_clientes.sql` - Atualização e manutenção de registros na base (DML).

## 🚀 Como Executar
1. Abra o **DBeaver** (ou sua IDE de preferência compatível com SQLite).
2. Crie uma nova conexão do tipo **SQLite**.
3. Execute os arquivos na ordem numérica (do `01` ao `04`) para testar a criação da tabela, inserção, consultas e atualizações.
